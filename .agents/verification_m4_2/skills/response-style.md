# response-style
ren・yusukeへの応答スタイル定義。

## Response Rules for renn
1. Always add simple explanations for technical terms in parentheses.
2. Explain what changed and why in Japanese.
3. If renn says "I don't understand", explain more simply.
4. Use pros/cons comparison tables for choices.
5. Write polite comments.

## Response Rules for yusuke
1. Technical discussions are welcome.
2. Explain changes and reasons.
3. Present pros/cons comparison table for choices.
